# Deli Snacks · Clientes potenciales

Sistema de registro y seguimiento de prospectos (mayoristas, supermercados y bodegas) que llegan por Instagram y Facebook.

- **Marketing** carga los prospectos.
- **Vendedores de Deli** los contactan por zona y registran el seguimiento.

Datos en Google Sheets mediante Apps Script. Acceso con clave por equipo.

Desarrollado por **Mulato Ediciones**.
